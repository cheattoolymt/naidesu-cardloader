📇 naidesu-cardloader

(何もかも)ないです — バイナリ ⇄ 紙のパンチカード（A4 / 300dpi）
🖨️

作成 (Creator)

ファイル → カード画像(PDF / PNG / JPG) を作って印刷。1KB / 2KB モードを選んで自動分割。
🔍

読み取り (Decoder)

スキャン画像/写真/PDF → 四隅を自動検出してバイナリに復元・結合。
使い方
① Creator でファイルを選び、カードを PDF などで出力 → A4 に等倍印刷
② 印刷物を 300dpi 程度でスキャン（または正面から撮影）
③ Decoder に読み込む → 四隅の黒■を自動検出 → ズレたら赤枠をドラッグ補正
④ 「解析して追加」→ 全ページ揃ったら「結合して保存」で元ファイルが復元されます

仕様: A4限定 / 300dpi想定 / 1セル=1bit。
・1KBモード: 96×96セル・1ページ最大 1140 byte（マスが大きく読み取り安定・推奨）
・2KBモード: 136×136セル・1ページ最大 2295 byte（枚数を約半分に）
読み取り側はモードを自動判別します。
